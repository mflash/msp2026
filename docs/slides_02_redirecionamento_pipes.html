Fundamento Universal

Os Três Canais Padrão (File Descriptors)

Todo processo Unix nasce conectado a 3 fluxos:

Descritores de Arquivo

  • 0 stdin (Entrada Padrão)
    Teclado por padrão; aceita dados via redirecionamento ou pipe.
  • 1 stdout (Saída Padrão)
    Terminal por padrão; resultados normais do comando.
  • 2 stderr (Saída de Erros)
    Terminal por padrão; diagnósticos e exceções.

❓ Por que separar saída e erro? Para salvar relatórios limpos sem misturar avisos neles!

- Fazer a pergunta retórica aos alunos: "Se os dois aparecem na tela do mesmo jeito, por que o Unix criou dois canais diferentes?" - Mostrar a clareza de separar o produto do trabalho das mensagens de controle.
Na Prática

Operadores de Redirecionamento

Conectando canais a arquivos em disco:

Sobrescrita vs. Concatenação

# Sobrescreve o arquivo (cria se não existir)
date > agora.txt
cat agora.txt

# Acrescenta ao final sem apagar o conteúdo
date >> agora.txt
cat agora.txt

⚠️ Cuidado com >: ele trunca o arquivo instantaneamente antes de executar.

Separando Sucesso e Falha

# Canal 1 em ok.txt, Canal 2 em erros.log
ls -l /root /home 1> ok.txt 2> erros.log

# Silenciando erros no "buraco negro"
ls -l /root 2> /dev/null

# Fundindo stderr no stdout (lê-se: 2 para onde 1 aponta)
./meu_script > saida_completa.log 2>&1

O /dev/null descarta dados imediatamente com custo zero de I/O.

- Enfatizar a sintaxe `2>&1`: ler em voz alta "mande o canal 2 para onde o canal 1 está apontando". - Mostrar que a ordem importa: `> arquivo 2>&1` funciona; `2>&1 > arquivo` não.
O Conector Mágico

O Pipe (|) e o Buffer em RAM

Conectando a saída de um processo à entrada do próximo sem disco:

Zero Disco Intermediário

Sem criar arquivos temporários como temp1.txt ou temp2.txt que poluem o sistema de arquivos.

Buffer Gerenciado em RAM

O kernel aloca um buffer circular em memória (tipicamente 64 KB). Se encher, o emissor pausa; se esvaziar, o receptor espera.

Execução Concorrente

Os programas rodam ao mesmo tempo em paralelo, aproveitando múltiplos núcleos da CPU.

comandoA | comandoB ➔ stdout do comandoA é conectado diretamente ao stdin do comandoB!

- Desfazer o mito de que o comando A roda até o fim e só depois o comando B inicia. - Explicar que os processos são criados juntos e transmitem blocos de dados em streaming.
Demonstração Interativa

Construindo um Pipeline Passo a Passo

Desafio: "Quais são os shells mais utilizados pelos usuários do sistema?"

# 1. Dado cru (campos separados por ':' no /etc/passwd)
cat /etc/passwd | head -n 3

# 2. Extrai apenas o 7º campo (o caminho do shell)
cut -d':' -f7 /etc/passwd | head

# 3. Ordena para agrupar ocorrências iguais
cut -d':' -f7 /etc/passwd | sort | head

# 4. Conta as repetições de cada shell vizinho
cut -d':' -f7 /etc/passwd | sort | uniq -c

# 5. Ordena numericamente reverso (do mais usado ao menos usado!)
cut -d':' -f7 /etc/passwd | sort | uniq -c | sort -nr

💡 Regra de Ouro do uniq: O comando uniq só elimina repetições imediatamente vizinhas. Por isso o sort deve sempre vir antes!

- Rodar cada linha individualmente no terminal antes de adicionar o próximo pipe. - Mostrar aos alunos o resultado mudando a cada filtro adicionado.
Mundo Real

Pipelines na Web e o Divisor tee

Processando dados de APIs REST ao vivo e gravando em disco:

Extraindo e Limpando Emails de uma API JSON

curl -s https://jsonplaceholder.typicode.com/users \
  | grep '"email"' \
  | cut -d':' -f2 \
  | tr -d '", ' \
  | sort \
  | head -n 5 \
  | tee emails_top5.txt

O que o comando faz:

  • curl -s: baixa o JSON silenciosamente sem barra de progresso.
  • grep + cut + tr: filtra e limpa aspas/vírgulas.
  • sort + head: ordena e seleciona o topo.

O Divisor em "T" (tee):

O tee copia o fluxo de dados em duas direções simultâneas:
1. Exibe o resultado na tela (stdout)
2. Grava no arquivo (emails_top5.txt)

- Mostrar que a ferramenta serve para JSON e APIs da nuvem tanto quanto para arquivos de sistema locais. - Ter o plano B em mente caso a internet falhe: `du -ah ~ | sort -rh | head -n 5`.
Repertório

Caixa de Ferramentas de Filtros de Texto

Comandos essenciais para o dia a dia:

Busca e Seleção

  • grep "padrão": filtra linhas.
  • head -n N: primeiras N linhas.
  • tail -n N -f: últimas linhas e tempo real.

Transformação

  • cut -d',' -f1,3: colunas por delimitador.
  • tr 'A-Z' 'a-z': traduz caracteres.
  • sed 's/antigo/novo/g': substituição.

Agrupamento & Estatística

  • sort -n -r: ordenação numérica reversa.
  • uniq -c: contagem de repetidos.
  • wc -l: contagem de linhas e palavras.
- Reforçar que não precisam decorar sintaxes exatas agora; o manual online traz a tabela completa de referência rápida.
